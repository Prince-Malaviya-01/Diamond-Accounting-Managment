यह बहुत ही महत्वपूर्ण और व्यावहारिक (practical) सवाल है! जो सेटअप हमने आपके लिए किया है, उसका सबसे बड़ा फायदा यही है कि कोड अपडेट करना अब बच्चों का खेल है और इसमें केवल 10 सेकंड लगेंगे।

यहाँ पूरा स्टेप-बाय-स्टेप वर्कफ़्लो (Workflow) दिया गया है:

💻 भाग 1: अपने लोकल विंडोज पीसी पर (Local PC Tasks)
जब आप अपने कंप्यूटर पर कोड में कोई भी बदलाव (जैसे बटन का रंग बदलना, टेक्स्ट बदलना, या नया फ़ीचर जोड़ना) कर लेते हैं, तो ये करें:

अगर आपने फ्रंटएंड (React/Frontend) में बदलाव किया है: टर्मिनल खोलें और फ्रंटएंड को फिर से कंपाइल (Build) कर लें:

powershell
cd d:\Magic\frontend
npm run build
बदलावों को गिटहब (GitHub) पर भेजें: अपने लोकल टर्मिनल में d:\Magic (रूट फोल्डर) पर जाएं और यह रन करें:

powershell
cd d:\Magic
git add .
git add -f frontend/dist    # (अगर फ्रंटएंड बदला है, तो इसे फोर्स ऐड करना ज़रूरी है!)
git commit -m "Updated dashboard UI"
git push origin main
अब आपका नया कोड गिटहब पर सुरक्षित अपलोड हो चुका है।

☁️ भाग 2: अपने AWS क्लाउड सर्वर पर (AWS Server Tasks)
अब अपने नए कोड को लाइव सर्वर पर लागू करने के लिए:

अपने सर्वर से कनेक्ट करें (SSH):

powershell
cd C:\Users\admin\Downloads
ssh -i "diamond-key.pem" ubuntu@13.234.172.221
नया कोड गिटहब से पुल (Download) करें: सर्वर के अंदर जाकर केवल यह एक कमांड चलाएं:

bash
cd /home/ubuntu/Magic
git pull
(यह कमांड गिटहब से केवल बदले हुए कोड को तुरंत डाउनलोड कर लेगा)

PM2 को रीस्टार्ट करें: ताकि आपका बैकएंड और वर्कर नए पाइथन कोड को लोड कर लें:

bash
pm2 restart all
बस हो गया! 🌟 आपको Nginx या डेटाबेस को छूने की भी ज़रूरत नहीं है। आपकी वेबसाइट पर नए बदलाव तुरंत लाइव हो चुके हैं!
